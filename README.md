The office printer finally answers back: **"Print queue: 14 jobs ahead of yours. I have read every one. Yours is the worst."** — no jam, no error code, no counting of sheets. Just a machine quietly doing its job, reading every document that passes through it, and forming an opinion. Of everything it has ever printed, yours is the worst.

## Run it

```sh
python3 main.py
```
